# Brand concept prompts

Reference: the established BillMinder receipt and check identity used by the Android companion app.

## 01 Minimal receipt check

Create a premium desktop app logo for BillMinder for PC. Preserve the recognizable receipt with a green check from the reference, but simplify it into a clean Windows software icon. Use a light blue receipt, deep navy outline, and vivid green check. Strong silhouette, balanced geometry, no text, no mockup, no device frame, no background plate. Centered with generous transparent padding. Export as a true RGBA PNG with alpha zero outside the mark.

## 02 Application window

Create a polished Windows application icon for BillMinder for PC. Combine a compact desktop window frame with the established light blue receipt and green check. Deep navy and cobalt blue with restrained depth, crisp edges, and a professional utility-software feel. No text, no currency symbol, no busy detail. Transparent background.

## 03 Wordmark

Create a horizontal wordmark that reads exactly "BillMinder for PC". Pair the established receipt and green check icon with a confident modern sans serif. BillMinder should lead, with "for PC" clearly secondary. Navy, light blue, and green only. Transparent background, excellent readability at GitHub README size.

## 04 Desktop emblem

Create a compact emblem for BillMinder for PC using a desktop monitor and the established receipt with green check. Keep it geometric, restrained, and recognizable at 32 pixels. Deep navy, light blue, and green. No text and no background. True transparency.

## 05 Abstract companion mark

Create an abstract companion mark for BillMinder for PC. Suggest a desktop screen, a bill, and completion without literal clutter. Stay in the established navy, light blue, and green family. Strong silhouette, minimal detail, no text, and a transparent background.
